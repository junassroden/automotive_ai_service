## Task selection

No dataset supports a verified road-vehicle future-failure predictor, DTC classifier, or broad fleet maintenance model. The only selected training task is a narrow laboratory-cell prognostics experiment: estimate remaining discharge cycles to 1.4 Ah for NASA cells whose local README documents that threshold and whose measured positive capacity sequence crosses it. EOL is not inferred for other cohorts. Evaluation holds out whole cells, never random rows.

The selected cells are B0005, B0006, and B0018. The 1.4 Ah criterion is documented for their cohort; cells with no positive initial capacity above threshold, no valid crossing, or unresolved very-low capacity anomalies are excluded. Capacity records at or below zero are treated as invalid measurements, not EOL observations. Cohort inclusion/exclusion decisions are listed in `dataset_suitability.json`.

## Dataset inventory CSV

`dataset_inventory.csv` has one row per recursively inspected local file, with path, file type, bytes, SHA-256, row/column counts where measurable, column names, missing-value counts, duplicate-row counts, and inspection status. The JSON report contains the grouped per-file schema, source/license evidence, and task decisions. Row totals across duplicate copies are not treated as independent observations.

The scanner does not impose universal valid-value ranges where dataset documentation does not define them. Field-specific checks for the selected battery task reject non-finite and nonpositive capacity values; exact exclusions and counts are recorded in the prepared dataset manifest.

## Filesystem limitations

- KIT extracted CSVs duplicate ZIP members; B0025-B0028 battery copies are byte-identical.
- EngineFaultDB lacks run IDs and named mappings for numeric class labels 0-3.
- Diesel workbook labels, source, license and supplied split grouping are unverified.
- CVFFAD is marked generated locally and has a placeholder DOI/missing license materials.
- Root Parquet/engine/service tables lack verified provenance or targets.
- Navarra sessions have telemetry but no confirmed maintenance outcomes; one bike is not a fleet.
- LEVIN has local documentation but no raw measurements. AI4I is synthetic industrial data.
- No raw data was changed or extracted.
